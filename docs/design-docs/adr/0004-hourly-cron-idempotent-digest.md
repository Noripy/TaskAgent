# ADR-0004: 日次コミットは毎時 Cron + 冪等ジョブで実現する

- 状態: Accepted
- 日付: 2026-09-17

## 決定
Cron を毎時 0 分に起動し、ユーザーの `timezone` と `digest_hour` が一致するときだけ当日分をコミットする。`daily_digests.content_hash` で内容が変わらなければ GitHub に触らない。失敗分は次の時間帯に最大 3 件リトライ。

## 代替案
- Workflows: 再試行・可観測性が標準。→ 現段階では過剰。ジョブ数が増えたら移行（ADR を追加）。
- Queues: Paid 必須で不可。

## 結果
UI に「今すぐコミット」を用意し、Cron を待たずに確認できるようにした。
